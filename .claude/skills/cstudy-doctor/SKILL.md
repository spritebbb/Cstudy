# Cstudy 环境体检

跑项目自带的自检脚本，然后把结果翻译成人话。

## 怎么跑

```
.venv\Scripts\python.exe scripts\smoke_test.py
```

（用户自己也可以双击 `环境自检.bat`，效果一样。）

脚本会逐项打印 `[OK]` 或 `[失败]`，最后给一个 `通过 N/M 项` 的汇总。

## 每一项是什么意思

| 检查项 | 它在确认什么 | 失败了怎么办 |
|---|---|---|
| 读取 config.yaml | 配置文件能被解析 | 多半是缩进或中文标点写错了，改回 YAML 格式 |
| 打开数据库 | `data/cstudy.db` 能读写 | 软件可能还开着，先关掉软件再跑 |
| 考纲知识点 | 考纲数据已导入 | 跑 `.venv\Scripts\python.exe scripts\seed_syllabus.py` |
| DeepSeek 密钥已配置 | `.env` 里有 key | 让用户把密钥填进 `.env`（**不要替他猜密钥**） |
| 连接 DeepSeek | 网络通、密钥有效、模型名对 | 密钥错 / 余额不足 / 网络不通，逐个排除 |
| 找到 ffmpeg | 能取音频 | 安装命令：`winget install Gyan.FFmpeg`，装完**重开终端** |
| 找到 yt-dlp | 能下载视频 | 安装命令：`winget install yt-dlp.yt-dlp`，装完**重开终端** |
| 本地转写组件 | faster-whisper 可用、显卡是否识别到 | 显卡没识别到不致命，会自动用 CPU，只是慢 |
| B 站登录态 | cookie 还在、没过期 | 双击 `扫码登录.bat` 重新扫码 |
| PyQt6 界面 | 主窗口能创建 | 依赖装坏了，重装 `requirements.txt` |

## 报告怎么说

- 全过：一句话告诉用户"环境没问题，可以双击 启动软件.bat 了"。
- 有失败：**只讲失败的那几项**，每项给"什么坏了 → 为什么 → 怎么做"。
  没失败的不用复述，免得刷屏。
- 区分**致命**和**不致命**：
  - 致命（软件根本跑不起来）：配置、数据库、PyQt6
  - 只影响部分功能：B 站登录态（只影响抓字幕）、显卡（只是变慢）、
    ffmpeg/yt-dlp（只影响没有 CC 字幕的视频）

## 边界

- 只读不改：不要顺手改配置或删数据库。
- 需要装软件时，把命令给用户（或征得同意后用 winget 装），不要默默装。
- 密钥内容不要打印出来。
